## ✦ Charte Graphique Officielle

Le site suit scrupuleusement la charte épurée inspirée de [**Multi-Motors**](https://multi-motors.fr) :

1. **Noir sur blanc** : Fond blanc pur (`#FFFFFF`), texte noir (`#000000`).
2. **Le pointillé comme signature** : Contours en pointillés de **2 px** (`border: 2px dashed rgba(0,0,0,0.45)`). Ils deviennent pleins et noirs au survol avec une légère translation verticale.
3. **Typographie Glacial Indifference** :
   - Titres et boutons en **capitales espacées** (`letter-spacing: 0.12em` à `0.15em`).
4. **Vitrine directe** : Accès direct aux sites et projets via leurs logos cliquables.
